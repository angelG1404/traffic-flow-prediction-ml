# Traffic Flow Prediction using Machine Learning

## Overview

This project predicts traffic flow at toll stations using Machine Learning techniques.

The workflow includes:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model training
- Model evaluation

---

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

---

## Machine Learning Models

- Random Forest
- Linear Regression

---

## Results

Accuracy: 93%

---

## Dataset

Traffic flow records collected from toll stations.
